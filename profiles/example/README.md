# example profile

A worked custom profile, showing every optional piece at once:

| File | Shows |
|---|---|
| `profile.env` | the addressee |
| `persona.md` | where a voice goes, and that it is optional |
| `vocabulary.txt` | domain synonyms for recall expansion, and why short acronyms are dangerous |
| `feedback/plan-substantial-work-to-files.md` | a **working preference** — the kind of rule that belongs in a profile rather than the shared starter set |

Copy the directory, rename it, delete what you do not want.
