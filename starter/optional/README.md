# Optional rules — not installed by default

These are **working preferences**, not engineering truths. Reasonable people run projects
differently, so they are not part of the starter set that every install receives; copy one into your
`feedback/` if you want it.

That distinction is the line the starter set is selected on, and it is the reason this directory
exists at all: `starter/feedback/` is for things that are true regardless of how you like to work.
